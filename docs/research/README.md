## Como usar

- Use busca textual para encontrar termos como `breakout`, `moving average`, `transaction costs`, `Sharpe`, `drawdown`, `out-of-sample` e `data-snooping`.
- Ao transformar uma ideia em codigo, registre a hipotese em `STRATEGY_REVIEW.md` antes de implementar.
- Valide qualquer estrategia nova com custos, slippage, comparacao contra buy-and-hold e numero minimo de trades.
